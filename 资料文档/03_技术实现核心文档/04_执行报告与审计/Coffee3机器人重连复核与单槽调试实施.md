# Coffee3Close 机器人重连复核与单槽调试

## 审批边界

本轮按最终审批实施 Coffee3Close。Coffee2Open、公共设备协议、nanoMODBUS、Flash 和 OTA 不在本轮修改范围内。此前讨论的网络消抖也不包含在本轮动作调度改动中。

- 沿用 `Coffee3RobotTransaction_t`、`Coffee3RobotPhase_e` 和工作流已有的设备终态匹配机制，不新增任务或动作状态机。
- 普通调试动作不能覆盖在途动作。整段订单制作或相关取放业务释放机器人后，优先执行等待槽中的一条调试动作，再开始下一段业务。
- 等待槽容量为一，后来的请求明确拒绝，不以“保留最新”方式覆盖已接受的请求。
- 工程师负责调试动作造成的现场位置、持杯等变化，固件不自动补偿该变化。
- 重发间隔至少 3000 ms，首次尝试之外最多五次。允许重试的前提是尚未尝试发布动作线圈，确认不存在重复运动风险；已经尝试发布但响应丢失的交易先复核，不能直接重发。
- 命令位持续为 1 时等机器人接取，不反复清 0 写 1。已经确认接取的 0/0 等待完成，不重发。

## 重连证据

网络恢复和机器人运行状态不代表当前动作已经完成。交易记录跨 TCP 重连保留，但不承诺跨 MCU 掉电或复位恢复订单。

| 交易证据 | 处理 |
| --- | --- |
| 已确认接取，命令/完成位为 0/0 | 保持运动等待，不重发 |
| 命令位为 1，完成位为 0 | 保持待接取，受接取期限约束 |
| 未确认接取且命令/完成位为 0/0 | 保留不确定性，不凭空宣称接取，不自动重发 |
| 完成位为 1 | 保存完成证据后清位并读回确认 |
| 已观察完成，但清位响应丢失，重连后完成位为 0 | 依据保留的完成证据完成确认，不退回运动中 |
| 明确超时或协议矛盾 | 明确记录动作/来源/命令 ID/阶段，按既有失败路径处理 |

接取、动作执行和通信恢复均需有期限。TCP 重连不能清空重试次数，也不能无限重置动作计时。重连期间保持当前工作流步骤，明确失败前不因一次通信事件直接宣判整单失败。

## 验证方法

`tests/test_coffee3_robot_execution.py` 加载 GCC Debug ELF，在 ARM 指令仿真器中执行实际编译的机器人函数。Modbus IO、日志和 RTOS 时间接口被替代为可控制的测试端点；交易结构布局从 ELF 的 DWARF 信息读取。

这能验证函数级握手判断、状态保留及超时边界，但不代表完成了实际机器人、FreeRTOS 调度、TCP 网络或机械联调。

测试环境：

```powershell
python -m pip install --target tmp/robot-test-deps unicorn pyelftools
GCC-ARM/.tools/python/cmake/data/bin/cmake.exe --build GCC-ARM/build/Coffee3Close-Debug -j 4
python -m unittest discover -s tests -v
```

改动前已用该方法复现两项失败：未确认接取的 0/0 被判为已接取；清完成位响应丢失后无法凭保留证据结束动作。其余三个基础握手场景通过。

## 上板验收

1. 在订单机器人动作中提交一条调试动作：日志说明暂存；原动作继续。再次提交调试动作：明确拒绝，原等待指令不变。
2. 订单还在出冰、出料或相关取放流程时，暂存的调试动作不能抢走机器人。业务释放后执行，下一段业务不得先抢占。
3. 分别在命令发布前、待接取、已接取运动中、完成位置位、清位响应返回前切断 TCP，再恢复。核查完整命令 ID、完成确认次数和动作次数。
4. 已接取的 0/0 不重发；命令保持 1 不反复触发；无法证明接取的 0/0 不打印“已接取”。
5. 制造发布前可重试故障：最多五次额外尝试，相邻间隔不小于三秒；重新连接不重置计数。
6. 长时间未接取、未完成或无法恢复通信时，日志区分原因并终止等待；不能因不断重连永久等待。
7. 核查本体控制的 TCP-only 边界，以及停止等本体命令对在途交易的反馈。普通调试完成不能被工作流误认为原订单动作完成。

实际机器人测试由工程师执行；本轮不自动下载或驱动设备。

- “5次/3秒”仅指确认尚未尝试发布动作线圈之前的准备重试。已经尝试写动作线圈但响应丢失时，不能证明机器人没有接取，不自动再次触发。
- 上次终态快照 `s_xLastTransaction` 保留完整命令、来源、接取/完成证据和终止结果，仅为 RAM 诊断数据，不承诺主控复位后的动作恢复。
- ARM函数测试不覆盖完整RTOS任务交错、真实断线时序和机械位置，仍必须执行上述上板清单。
