## 整理动作说明

### 1. 消除「店中店咖啡机工程核心实现资料」的分家碎片

原顶层孤立的 `店中店咖啡机工程核心实现资料/架构方案/Coffee2修正版程序设计方案.md`
已并入 `03_技术实现核心文档/店中店咖啡机工程核心实现资料/01_架构设计/`，与主目录合并。

> 数据核对：以 COFFEE2 源码为准的文档核对结果见 **`源码核对报告_Coffee2_2026-08-11.md`**（同目录）。

### 2. 产品核心实现资料各自独立（不跨产品合并）

按你的要求，咖啡机与奶茶机的核心实现资料**分别独立成目录**，互不合并。
两产品都使用到的公共层文档（日志、网络协议栈、语法规范、transport）各自保留一份，互不干扰后续单产品的重构演进。

### 3. 咖啡机核心文档以 COFFEE2 源码逻辑为基准归纳

咖啡机核心资料按 **COFFEE2 工程源码模块**（参考 `Application/UserAPP/Coffee2App/`）归并为 7 类：

| 新目录 | 对应源码模块 / 内容 | 说明 |
|---|---|---|
| `01_架构设计` | 架构总览（权威入口）、机器人调度、设备挂载、已合并原始文档归档 | 见 `README_导览.md` |
| `02_源码解读` | `Comm_Log / Device / Bus / Server / Robot / Workflow` 实现报告与协议栈层 | 实现报告 + 协议栈/传输层拆解 |
| `03_调试与测试` | 使用与调试手册、Keil 仿真排查、单机测试、波特率同步 | 调试与验收操作类 |
| `04_执行报告与审计` | Coffee1 工作流提取、Coffee2 防呆审查、注释审计与编译校验 | 阶段审查报告 |
| `05_语法与规范` | C 函数指针、指针语法、注释规范 | 通用语言/编码规范 |
| `06_日志` | 日志架构、串口发送、日志排障、死机日志 | 通用日志链路 |
| `07_网络协议栈` | lwIP 解读与配置清单 | 通用网络栈 |

> 其中 `01_架构设计/` 中高度重叠的四份原始架构文档（五层架构/工程拆解闭环/任务通信/修正版方案）
> 已归纳进 `Coffee2_架构总览（以源码为基准）.md`，原文档移入 `已合并-原始文档归档/` 保留。
> 各产品目录均新增 `README_导览.md` 作为入口。

### 4. 工具链特性资料与产品实现分离

GCC / MDK 的**构建、编译、内存链接（CCM）等工具链专属资料**统一收归 `02_工具链特性资料/`，
与产品工程实现彻底分开。

### 5. 对接项目资料按项目与用途归类

- 咖啡机对接资料拆为「咖啡机对外协议」与「共用外设协议」（制冰机/电能表/称重/晟枢落杯落盖等）。
- 奶茶机对接资料按 Modbus 通讯、正泰电能表、称重压力传感器分类。
