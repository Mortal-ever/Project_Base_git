# Modbus TCP 控制协议参考手册

> 自动奶茶机 — Modbus TCP Server 协议
> 版本：1.0

---

## 1. 概述

终端作为 Modbus TCP Server，外部系统作为 Client 发起请求。通过本协议，集成方可以：

- 读取设备制作状态（空闲/制作中）
- 读取上次制作结果（成功/失败）
- 发送饮品制作指令并触发制作
- 中止当前制作
- 读取设备运行状态

### 1.1 协议版本

标准 Modbus TCP（MBAP 头 + PDU），符合 Modbus 协议规范 PI-MBUS-300。

### 1.2 连接参数

| 参数 | 值 | 说明 |
|------|------|------|
| 终端 IP | 根据实际网络环境填入 | — |
| 端口 | **1502** | — |
| 协议 | TCP | 长连接 |
| 并发连接 | 支持多客户端 | 无连接数限制 |
| 认证 | 无 | 任何可达客户端均可读写 |

### 1.3 启用条件

Modbus Server 默认**关闭**。若客户端无法连接 1502 端口，请联系终端运维方确认是否已启用此功能。

## 2. 帧格式

### 2.1 MBAP 头（7 字节）

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 2 | Transaction ID | 事务标识，由客户端设置，响应原样返回 |
| 2 | 2 | Protocol ID | 协议标识，固定 0x0000 |
| 4 | 2 | Length | 后续字节数（Unit ID + PDU） |
| 6 | 1 | Unit ID | 单元标识 |

### 2.2 PDU（功能码 + 数据）

| 偏移 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 7 | 1 | Function Code | 功能码 |
| 8+ | 变长 | Data | 数据域 |

### 2.3 异常响应格式

当请求无法正常处理时，响应 PDU 格式为：

| 字节 | 值 | 说明 |
|------|------|------|
| Function Code | 请求功能码 \| 0x80 | 最高位置 1 表示异常 |
| Exception Code | 异常码 | 0x01 或 0x02 |

---

## 3. 支持的功能码

| 功能码 | 代码 | 名称 | 说明 |
|--------|------|------|------|
| FC01 | 0x01 | 读线圈（Read Coils） | 读取制作状态等开关量 |
| FC03 | 0x03 | 读保持寄存器（Read Holding Registers） | 读取状态值、结果值、产品标识 |
| FC06 | 0x06 | 写单寄存器（Write Single Register） | 写入触发标志或中止标志 |
| FC16 | 0x10 | 写多寄存器（Write Multiple Registers） | 批量写入产品标识 |

其他功能码（如 FC02、FC04、FC05、FC15 等）均返回异常码 0x01（非法功能）。

---

## 4. 寄存器映射

### 4.1 线圈（Coils）— 地址空间 0~99

| 地址 | 名称 | 读写 | 数据类型 | 说明 |
|------|------|------|----------|------|
| 0 | isProducing | 只读 | BOOL | false(0)=空闲，true(1)=制作中 |
| 1~99 | — | — | — | 保留，未使用 |

### 4.2 保持寄存器（Holding Registers）— 地址空间 0~199

| 地址 | 名称 | 读写 | 数据类型 | 说明 |
|------|------|------|----------|------|
| 0 | isProducing | 只读 | UINT16 | 0=空闲，1=制作中（与线圈0镜像） |
| 1 | productionResult | 只读 | UINT16 | 0=无结果，1=成功，2=失败 |
| 2~9 | — | — | — | 保留 |
| 10~39 | productIdentifier | **读写** | UTF-16BE | 产品标识，最大30字符，0x0000终止 |
| 40 | triggerMaking | **读写** | UINT16 | 写1触发制作，触发后自动清零 |
| 41 | triggerAbort | **读写** | UINT16 | 写1中止制作，触发后自动清零 |
| 42~49 | — | — | — | 保留 |
| 50 | runningState | 只读 | UINT16 | 设备运行状态（见下表） |
| 51~199 | — | — | — | 保留 |

### 4.3 设备运行状态枚举（寄存器50）

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | online | 在线正常运行 |
| 1 | warning | 警告状态 |
| 2 | error | 错误状态 |
| 3 | startup | 启动中 |
| 4 | down | 离线 |

> **当前实现**：寄存器50已接入设备健康状态。任务启动阶段为3；网络或Modbus监听端点未就绪为4；
> 工作流进入需要人工确认的安全错误为2；未注册设备执行器为1；其余正常状态为0。正常制作中仍为0，
> 是否正在制作应读取寄存器0。状态改变会立即写入，状态不变时每5秒输出一条状态心跳日志。

### 4.4 可写地址汇总

| 地址范围 | 名称 | 用途 |
|----------|------|------|
| 10~39 | productIdentifier | 写入产品标识 |
| 40 | triggerMaking | 写入1触发制作 |
| 41 | triggerAbort | 写入1中止制作 |

**写入其他任何地址将返回异常码 0x01。**

## 5. 功能码详细说明

### 5.1 FC01 — 读线圈

**请求 PDU：**

| 字节 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | Function Code | 0x01 |
| 1~2 | 2 | Start Address | 起始地址（大端） |
| 3~4 | 2 | Quantity | 线圈数量（1~2000，大端） |

**正常响应 PDU：**

| 字节 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | Function Code | 0x01 |
| 1 | 1 | Byte Count | 返回数据字节数 N |
| 2~N+1 | N | Coil Data | 位打包数据，LSB优先，8线圈/字节 |

**异常响应：**

- 0x81 0x01 — 不支持的功能码
- 0x81 0x02 — 起始地址+数量 > 100，或数量不在 1~2000 范围

**示例 — 读取制作状态：**

```
请求：00 01 00 00 00 06 01  01 00 00 00 01
       ↑TID            ↑UID ↑FC ↑Addr=0 ↑Qty=1

响应：00 01 00 00 00 04 01  01 01 01
       ↑TID            ↑UID ↑FC ↑BC=1 ↑Data=0x01(bit0=1,制作中)
```

### 5.2 FC03 — 读保持寄存器

**请求 PDU：**

| 字节 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | Function Code | 0x03 |
| 1~2 | 2 | Start Address | 起始地址（大端） |
| 3~4 | 2 | Quantity | 寄存器数量（1~125，大端） |

**正常响应 PDU：**

| 字节 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | Function Code | 0x03 |
| 1 | 1 | Byte Count | 返回数据字节数 N = Quantity x 2 |
| 2~N+1 | N | Register Data | 寄存器值，大端序，每2字节一个寄存器 |

**异常响应：**

- 0x83 0x02 — 起始地址+数量 > 200，或数量不在 1~125 范围

**示例 — 读取制作状态和结果：**

```
请求：00 02 00 00 00 06 01  03 00 00 00 02
       ↑TID            ↑UID ↑FC ↑Addr=0 ↑Qty=2

响应：00 02 00 00 00 07 01  03 04 00 01 00 01
       ↑TID            ↑UID ↑FC ↑BC=4 ↑Reg0=1(制作中) ↑Reg1=1(成功)
```

### 5.3 FC06 — 写单寄存器

**请求 PDU：**

| 字节 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | Function Code | 0x06 |
| 1~2 | 2 | Address | 目标地址（大端） |
| 3~4 | 2 | Value | 写入值（大端） |

**正常响应 PDU：** 回显请求 PDU（功能码 + 地址 + 值）

**异常响应：**

- 0x86 0x01 — 目标地址不在可写范围（非 10~39、40 或 41）
- 0x86 0x02 — 目标地址 >= 200

**示例 — 触发制作：**

```
请求：00 03 00 00 00 06 01  06 00 28 00 01
       ↑TID            ↑UID ↑FC ↑Addr=40 ↑Value=1

响应：00 03 00 00 00 06 01  06 00 28 00 01
       ↑TID            ↑UID ↑FC ↑Addr=40 ↑Value=1（回显）
```

**示例 — 中止制作：**

```
请求：00 04 00 00 00 06 01  06 00 29 00 01
       ↑TID            ↑UID ↑FC ↑Addr=41 ↑Value=1

响应：00 04 00 00 00 06 01  06 00 29 00 01
       ↑TID            ↑UID ↑FC ↑Addr=41 ↑Value=1（回显）
```

**示例 — 写入只读地址（失败）：**

```
请求：00 05 00 00 00 06 01  06 00 00 00 01
       ↑TID            ↑UID ↑FC ↑Addr=0 ↑Value=1

响应：00 05 00 00 00 03 01  86 01
       ↑TID            ↑UID ↑FC=0x86(异常) ↑EC=0x01(非法功能)
```

### 5.4 FC16 — 写多寄存器

**请求 PDU：**

| 字节 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | Function Code | 0x10 |
| 1~2 | 2 | Start Address | 起始地址（大端） |
| 3~4 | 2 | Quantity | 寄存器数量（1~123，大端） |
| 5 | 1 | Byte Count | 后续数据字节数 = Quantity x 2 |
| 6~N+5 | N | Register Data | 寄存器值，大端序 |

**正常响应 PDU：**

| 字节 | 长度 | 字段 | 说明 |
|------|------|------|------|
| 0 | 1 | Function Code | 0x10 |
| 1~2 | 2 | Start Address | 起始地址（大端） |
| 3~4 | 2 | Quantity | 写入数量（大端） |

**异常响应：**

- 0x90 0x01 — 任一目标地址不在可写范围
- 0x90 0x02 — 起始地址+数量 > 200，或数量不在 1~123 范围，或字节数不等于数量x2

## 6. 制作触发流程

### 6.1 标准触发流程

外部集成方触发饮品制作需按以下步骤操作：

```
步骤1：读取寄存器0（isProducing），确认设备空闲（值=0）
步骤2：写入产品标识到寄存器10~39（FC16）
步骤3：写入1到寄存器40（triggerMaking），触发制作（FC06）
步骤4：读取寄存器0，确认设备已进入制作中（值=1）
步骤5：轮询寄存器0，等待制作完成（值=0）
步骤6：读取寄存器1（productionResult），获取制作结果
```

### 6.2 时序图

```
外部集成方                终端
    |                          |
    |--- FC03 读寄存器0 ------->|  确认空闲
    |<-- 0（空闲）-------------|
    |                          |
    |--- FC16 写寄存器10~39 -->|  写入产品标识
    |<-- 写入成功 -------------|
    |                          |
    |--- FC06 写寄存器40=1 --->|  触发制作
    |                          |  (读取标识 → 清零 → 执行制作)
    |<-- 回显 -----------------|
    |                          |
    |--- FC03 读寄存器0 ------->|  确认制作中
    |<-- 1（制作中）-----------|
    |                          |
    |       ... 制作进行中 ... |
    |                          |
    |--- FC03 读寄存器0 ------->|  轮询等待完成
    |<-- 0（空闲）-------------|
    |                          |
    |--- FC03 读寄存器1 ------->|  读取结果
    |<-- 1（成功）或 2（失败）-|
    |                          |
```

### 6.3 触发后终端处理

1. 终端检测到寄存器40 == 1
2. 从寄存器10~39 读取产品标识
3. 清零寄存器10~39 和 40
4. 如果标识为空或设备正在制作，设置寄存器1 = 2（失败）
5. 否则解析标识并执行制作
6. 制作完成后设置寄存器1 = 1（成功）或 2（失败）

### 6.4 制作状态更新周期

- 制作状态（线圈0/寄存器0）每 **2秒** 更新一次
- 外部集成方读取到的状态可能有最多 2 秒的延迟

## 7. 中止制作流程

### 7.1 标准中止流程

```
步骤1：写入1到寄存器41（triggerAbort），中止制作（FC06）
步骤2：读取寄存器0，确认设备已回到空闲（值=0）
```

### 7.2 时序图

```
外部集成方                终端
    |                          |
    |--- FC06 写寄存器41=1 --->|  中止制作
    |<-- 回显 -----------------|
    |                          |
    |       ... 终端执行中止 ..|
    |                          |
    |--- FC03 读寄存器0 ------->|  确认空闲
    |<-- 0（空闲）-------------|
    |                          |
```

> **注意**：中止指令在设备空闲时写入不会产生副作用，终端会忽略空闲状态下的中止请求。

## 8. 产品标识格式

### 8.1 编码方式

- **编码**：UTF-16BE（每个字符占 2 字节，大端序）
- **存储**：每个寄存器存储一个 UTF-16 码元
- **最大长度**：30 个字符（30 个寄存器）
- **终止**：遇 0x0000 寄存器值视为字符串结束
- **截断**：超过 30 字符的部分被截断

### 8.2 字符串示例

**英文标识 "LATTE"：**

| 寄存器地址 | 值（十六进制） | 字符 |
|-----------|---------------|------|
| 10 | 0x004C | L |
| 11 | 0x0041 | A |
| 12 | 0x0054 | T |
| 13 | 0x0054 | T |
| 14 | 0x0045 | E |
| 15~39 | 0x0000 | (终止) |

**中文标识 "拿铁"：**

| 寄存器地址 | 值（十六进制） | 字符 |
|-----------|---------------|------|
| 10 | 0x62FF | 拿 |
| 11 | 0x94C1 | 铁 |
| 12~39 | 0x0000 | (终止) |

### 8.3 指令格式

产品标识的格式由终端运维方配置决定。集成方需向终端运维方确认当前终端支持的标识格式。

**结构化标识**

使用分隔符将多个字段组合为一条标识，字段顺序和含义由终端运维方定义：

```
示例："ORD001-LATTE-OPT1,OPT2"
说明：第1段=订单号，第2段=产品标识，第3段=口味选项（逗号分隔）
```

> 具体字段数量、顺序、分隔符由终端运维方配置，集成方需获取对应的标识格式说明。

### 8.4 字符串长度限制

产品标识最大 **30 个字符**。超过 30 字符的部分将被截断。结构化标识请确保总长度不超过此限制。

## 9. 异常码参考

| 异常码 | 名称 | 触发条件 | 对应功能码 |
|--------|------|----------|-----------|
| 0x01 | Illegal Function | 发送不支持的功能码；写入只读寄存器地址 | 所有 |
| 0x02 | Illegal Data Address | 地址超出范围；数量不在合法范围；字节数不一致 | FC01/FC03/FC06/FC16 |

异常响应中功能码 = 请求功能码 | 0x80。例如 FC06 写只读地址返回 0x86 0x01。

---

## 10. 生产结果码参考

| 值 | 名称 | 触发条件 |
|----|------|----------|
| 0 | 无结果 | 初始状态，尚未触发过制作 |
| 1 | 成功 | 制作流程正常完成 |
| 2 | 失败 | 以下任一情况：标识为空；设备正在制作中；配方未找到；标识格式不匹配；制作过程异常 |

## 11. 完整通信示例

### 11.1 触发制作

**前提**：终端已启用 Modbus Server，且终端中存在对应配方的产品。

```
--- 步骤1：确认设备空闲 ---
发送：00 01 00 00 00 06 01 03 00 00 00 01
      [TID=1] [PID=0] [Len=6] [UID=1] [FC03] [Addr=0] [Qty=1]
接收：00 01 00 00 00 05 01 03 02 00 00
      [TID=1] [PID=0] [Len=5] [UID=1] [FC03] [BC=2] [Reg0=0(空闲)]

--- 步骤2：写入产品标识 "LATTE" 到寄存器10~14 ---
发送：00 02 00 00 00 11 01 10 00 0A 00 05 0A 00 4C 00 41 00 54 00 54 00 45
      [TID=2] [PID=0] [Len=17] [UID=1] [FC16] [Addr=10] [Qty=5] [BC=10]
      [Reg10='L'] [Reg11='A'] [Reg12='T'] [Reg13='T'] [Reg14='E']
接收：00 02 00 00 00 06 01 10 00 0A 00 05
      [TID=2] [FC16] [Addr=10] [Qty=5]

--- 步骤3：触发制作 ---
发送：00 03 00 00 00 06 01 06 00 28 00 01
      [TID=3] [FC06] [Addr=40] [Value=1]
接收：00 03 00 00 00 06 01 06 00 28 00 01
      [TID=3] [FC06] [Addr=40] [Value=1]（回显）

--- 步骤4：确认制作中 ---
发送：00 04 00 00 00 06 01 03 00 00 00 01
接收：00 04 00 00 00 05 01 03 02 00 01
      [Reg0=1(制作中)]

--- 等待制作完成 ---

--- 步骤5：读取制作结果 ---
发送：00 05 00 00 00 06 01 03 00 01 00 01
      [FC03] [Addr=1] [Qty=1]
接收：00 05 00 00 00 05 01 03 02 00 01
      [Reg1=1(成功)]
```

### 11.2 中止制作

```
--- 步骤1：中止当前制作 ---
发送：00 06 00 00 00 06 01 06 00 29 00 01
      [TID=6] [FC06] [Addr=41] [Value=1]
接收：00 06 00 00 00 06 01 06 00 29 00 01
      [TID=6] [FC06] [Addr=41] [Value=1]（回显）

--- 步骤2：确认已回到空闲 ---
发送：00 07 00 00 00 06 01 03 00 00 00 01
接收：00 07 00 00 00 05 01 03 02 00 00
      [Reg0=0(空闲)]
```

### 11.3 制作失败场景

```
--- 场景：设备制作中时再次触发 ---
发送：00 08 00 00 00 06 01 06 00 28 00 01
      [FC06] [Addr=40] [Value=1]（触发）

（触发成功回显，但终端检测到制作中，设置 productionResult=2）

--- 读取结果 ---
发送：00 09 00 00 00 06 01 03 00 01 00 01
接收：00 09 00 00 00 05 01 03 02 00 02
      [Reg1=2(失败)]
```

## 12. 限制与注意事项

| 项目 | 限制 | 说明 |
|------|------|------|
| 端口 | 1502 | 非标准 Modbus 端口 |
| 产品标识长度 | 最大 30 字符 | 寄存器10~39，每寄存器一个 UTF-16 码元 |
| 制作状态延迟 | 最多 2 秒 | 状态更新周期 |
| 寄存器50 | 设备健康状态 | 0正常、1警告、2安全错误、3启动中、4网络或监听离线 |
| 客户端认证 | 无 | 任何可达客户端均可读写所有允许的寄存器 |
| 并发制作 | 不支持 | 制作中触发新指令会被拒绝（productionResult=2） |
| 功能码 | 仅 4 种 | FC01/FC03/FC06/FC16 |
| 写保护 | 地址 10~39、40、41 | 其他地址写入返回异常码 0x01 |

## 13. 术语表

| 术语 | 说明 |
|------|------|
| MBAP | Modbus Application Protocol，Modbus TCP 的应用层帧头 |
| PDU | Protocol Data Unit，协议数据单元 |
| FC | Function Code，功能码 |
| Coil | Modbus 线圈，1 位布尔值 |
| Holding Register | Modbus 保持寄存器，16 位无符号整数 |
| LSB | Least Significant Bit，最低有效位在前 |
| Big-Endian | 大端序，高字节在前 |
